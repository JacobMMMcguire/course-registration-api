2026 Course Catalog

CPSC 1046. Introduction to Computer Science. 3 Credits.

An introduction to problem solving and programming using a high-level language.

Prerequisites: None.

CPSC 2206. Data Structures. 3 Credits.

Abstract data types, algorithm analysis, and their implementation.

Prerequisites: CPSC 1046.

CPSC 3305. Database Systems. 3 Credits.

Relational database design, normalization, and SQL.

Prerequisites: CPSC 2206.

Cross-listed with: MATH 3305.

CPSC 4407. Software Engineering. 3 Credits.

Software development lifecycle, requirements, design, testing, and project management.

Prerequisites: CPSC 2206 and CPSC 3305.

MATH 1046. Discrete Mathematics. 3 Credits.

Logic, set theory, combinatorics, and graph theory for computer science.

Prerequisites: None.

Cross-listed with: CPSC 1046.

CPSC 4900. Capstone Project. 6 Credits.

A culminating project applying skills learned throughout the program.

Prerequisites: CPSC 4407, CPSC 3305, and permission of instructor.
